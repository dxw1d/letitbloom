ASCII Flower Customizer
======================

WEBSITE
- Open flower-customizer.html in Chrome or Edge.
- Click CUSTOMIZE.
- Enter your own text. It becomes the ASCII character pattern and is shown as a signature.
- Upload a PNG, JPG, WEBP or GIF logo (max 6 MB). It is converted into colored ASCII characters below the flower.
- Adjust logo size with the slider.
- All processing is local in your browser. The image is not uploaded anywhere.

PYTHON
- Run: python flower_ascii.py
- Enter custom text when prompted. Press Enter to keep the default pattern.
- Keep flower_frames.bin beside flower_ascii.py.
- The terminal version supports a custom text pattern; image-logo upload is available in the website version.

Controls in the animation: SPACE pause/resume, R restart, Q or ESC quit (Python).
No third-party packages are required.
